# 🌊 Scenery – A Beautiful Ocean

A simple and visually attractive **Scenery Webpage** created as a college project at **Dezyne École College**.

The project uses **HTML and CSS** to create an underwater ocean-themed webpage with a full-screen background image, a large title, and a short description.

## 🎓 College Project

**College:** Dezyne École College  
**Project:** Scenery – A Beautiful Ocean  
**Type:** College Web Development Project

## 📌 About the Project

"Scenery" is a beginner-friendly web development project designed to demonstrate the basic use of:

- HTML structure
- CSS styling
- Background images
- Responsive viewport settings
- Text positioning
- Transparent backgrounds
- Full-screen background design

The webpage displays an underwater ocean scene with the title **"Scenery"** and the subtitle **"A Beautiful Ocean"**.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- 🌊 Beautiful underwater ocean background
- 📱 Responsive viewport configuration
- 🖼️ Full-screen background image
- 🎨 CSS-based styling
- 📍 Centered background positioning
- 🔒 Fixed background while scrolling
- 📝 Large and clear project title
